# Maxi Studio — Private Barber Studio ✂️👑

Sitio web oficial de **Maxi Studio** (Maxii Barbers), Private Barber Studio ubicado frente a la estación de **Metro Carlos Valdovinos** (Línea 5, Santiago de Chile).

---

## ✨ Características Principales

* 💈 **Identidad Visual Premium**: Estética moderna en tonos ámbar y carbón con efectos de iluminación neón y tipografía *Playfair Display* + *Inter*.
* ✂️ **Catálogo de Servicios & Inauguración**: Tarifas oficiales con precios de lanzamiento ($8.000 corte, $9.990 corte + diseño + cejas, $3.990 degradado y barba).
* 📸 **Portfolio de Trabajos Reales**: Galería interactiva filtrable por categoría con modal Lightbox para visualización en alta resolución.
* 📅 **Motor de Reservas Interactivo (4 Pasos)**:
  1. Selección de servicio
  2. Selección de barbero / profesional
  3. Selección de fecha y horarios disponibles en tiempo real
  4. Formulario de contacto con confirmación directa y enlace a WhatsApp (+56 9 2758 0406)
* 📍 **Ubicación Estratégica**: Badge oficial de Metro de Santiago e iframe interactivo de Google Maps.
* 📱 **100% Mobile First & Responsive**: Optimizado para tráfico proveniente de Instagram (`@maxii.barbers`).

---

## 🚀 Despliegue & Ejecución Local

Para correr el proyecto localmente sin dependencias:

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```
